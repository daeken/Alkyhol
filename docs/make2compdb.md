# Released Windows make2compdb

The unchanged Windows make2compdb **2026-09-15**, by Gabriel Berthiaume, shipped in
w64devkit 2.11.0 x64, runs through Alkyhol/Rosetta on physical M4. It is a second
released application alongside u-config. Its original Windows machine code parses
make output and emits Clang JSON compilation databases; Alkyhol supplies the real
process APIs. The PE is downloaded, SHA-256 checked and embedded unchanged. There
is no rebuild, patched executable, replacement parser or source-port substitution.

```sh
python3 tools/fetch_make2compdb_binary.py
python3 tools/run_make2compdb_binary.py --binary local/pe/make2compdb/make2compdb.exe --output local/pe/make2compdb/observation.json
```

## Binary process contracts

Two kernel32 names bring its explicit binary whitelist to 45; shell32 adds one
separately named import. These are Win64/16-bit UTF-16 adapters. The source ABI's
32-bit wide-character functions are not used.

| Import | Supported contract |
| --- | --- |
| GetCurrentDirectoryW | Actual absolute host current directory as UTF-16; zero-size query/insufficient capacity returns required units including NUL, successful copy excludes NUL from its count. No invented Windows drive mapping or SetCurrentDirectory support. Requires ProcessContext; bounded to 32767 units. |
| shell32!CommandLineToArgvW | Decodes valid-Unicode command lines in the exact canonical format generated by `windows_command_line`: quoted nonempty executable, one separator space and quoted arguments with encoded literal quotes/backslashes. Supports empty arguments, whitespace, surrogate pairs and trailing backslashes. Noncanonical/empty command lines and other Shell32 spellings fail explicitly; this is not general Shell32 parsing. Returns a real contiguous pointer/string allocation, limited to 64 live blocks and one MiB per block in its ProcessContext. |
| LocalFree | Actually frees exactly the original owned argv-block address; NULL succeeds. Foreign, interior, already-freed and other-context addresses fail. Other LocalAlloc/LocalReAlloc object types remain unsupported. Blocks left live are reclaimed at context destruction. |

Host units cover parser inverses, malformed/unsupported spellings, actual pointer/
string layout, full-width ownership/freeing, block limits, cross-thread/context
isolation, CWD sizing/termination and buffer errors. LocalFree has host tests only:
this released application retains its argv block until process exit. Native
application evidence covers its used Shell32/CWD paths, not every API boundary.

## Corpus and evidence

Sixteen owned cases include version/help, empty input, real GCC/Clang compile
commands, multiple files, nested make directories, quoted flags/filenames,
non-ASCII/surrogate-pair paths, ignored noncompile lines, stdin longer than the
16-KiB read chunk, and unknown CLI arguments with empty/space/quote/backslash/
Unicode values. The runner uses an actual Unicode/spaced working directory.
Compilation entries use explicit make-reported virtual directories so expected
output is independent of runner-specific CWDs. No compiler is launched and these
make listings do not access their declared directories.

Every status/stdout/stderr byte is checked exactly. No path, whitespace, JSON or
error normalization is used. Only one exact verified host loader prefix is removed.
Normal and forced-rebase host executions must agree. Windows receives and runs the
identical release PE/source/license files. PE/source/license/corpus identities and
clean matching revisions are checked; actual native results are frozen separately
at `pe/reference/make2compdb-windows-v1.json` and required by default. All 16
cases agree on native Windows, hosted Mac and physical M4 at `761fc2e`. Detailed
executed native/hosted/physical evidence is recorded in
[validation](validation.md). These are this application's tested paths, not general
Windows CRT, Shell32, graphics-binary or game compatibility.

Primary API contracts: [CommandLineToArgvW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-commandlinetoargvw),
[LocalFree](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-localfree)
and [GetCurrentDirectory](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getcurrentdirectory).

Strict-reference revision `3899551` passes all 27 CI jobs. Downloaded clean native/
hosted records and fresh clean physical M4 execution at that same revision agree
on all 16 cases and the unchanged release/corpus identities. See
[executed validation](validation.md) for CI links and precise test counts.
